# Ribo Project 1 — Personal Portfolio

## Folder structure
- `index.html` — main portfolio page
- `styles/style.css` — website styling
- `assets/profile.svg` — temporary profile image placeholder

## Run locally
Open `index.html` in a web browser. Replace `assets/profile.svg` with your own image if desired, and update the image path in `index.html`.

## Publish with GitHub Pages
1. Create a public GitHub repository named `ribo-project-1`.
2. Push these files to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Git commit requirement
Make at least 10 meaningful commits as you build and improve the project. Do not create duplicate commits just to reach the required number. You can make the initial structure, sections, styling, responsive layout, and final corrections in separate stages.
